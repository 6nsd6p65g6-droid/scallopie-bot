# موقع المصراتي للسيراميك والبرسلين

صفحة واحدة بالعربية، تُبنى مسبقاً لتظهر بسرعة ثم تعمل تفاعلياً في المتصفح.

## التشغيل

```
npm install
node build.mjs        # يبني الموقع في مجلد dist
npx tsc --noEmit      # فحص الأنواع
cd dist && python3 -m http.server 4310
```

## أين أعدّل؟

- البيانات كلها في `src/site-data.ts`: الأصناف، التصاميم الحقيقية وأوصافها، تصاميم البيوت والحمامات، الفيديوهات، وبيانات التواصل (فارغة حتى تصل من الشركة، والأقسام المرتبطة بها تظهر تلقائياً عند تعبئتها).
- التنسيق في `src/styles/` ويُجمع بترتيب أسماء الملفات في `dist/styles.css`.
- الصور الحقيقية في `public/designs/` بثلاثة أحجام لكل تصميم: `id.jpg` كبيرة، `id-t.jpg` للبطاقة، `id-w.jpg` صغيرة لجدار الواجهة.
- تصاميم البيوت والحمامات في `public/looks/` بثلاثة أحجام: `id.jpg` و`id-m.jpg` و`id-t.jpg`.
- رابط الموقع النهائي في `prerender.tsx` (المتغير `SITE_URL`).

## النشر المقترح

GitHub Pages: المصدر في الفرع `source`، وناتج `dist` في الفرع `main` لمستودع `<الحساب>.github.io`.
